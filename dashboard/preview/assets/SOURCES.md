# Official Unitree product images

The robot picker uses product images published by Unitree Robotics, downloaded
on 2026-11-13. Both PNG files are preserved unchanged, including transparency.
They are served locally so the preview does not depend on an external image host.

| Local file | Official product page | Original image |
| --- | --- | --- |
| `unitree-h2.png` | [Unitree H2](https://www.unitree.com/H2/) | [428 × 404 PNG](https://www.unitree.com/images/4bd5086c153f4729830aa43ee668d9df_428x404.png) |
| `unitree-g1.png` | [Unitree G1](https://www.unitree.com/g1/) | [428 × 404 PNG](https://www.unitree.com/images/fb1eee1cce424ca0893a3d426a55e004_428x404.png) |

The original images appear in Unitree's humanoid robot navigation, associated
with the H2 and G1 product links respectively. Product images belong to Unitree
Robotics; the repository's code license does not relicense these third-party
assets. They identify the robot models in this dashboard preview.
